==> Overallt -> need to install minimal debian (minimal OS)

=============================== Minimal Debian ====================
Having:
	+ Package manager: apt, dpkg (/usr/bin)
	+ Shell: (/bin/bash or bin/sh)
	+ Core utils: mv, cp, grep (/bin)
	+ Filesystem: mount, lsblk (/bin)
	+ Init system: systemd (/bin)
	+ Networking: ifup (/bin)
	
Not having:
	+ No GUI
	+ Kernel image + U-boot + firmware
	+ No compiler toolchains (gcc, make)
	+ No python
