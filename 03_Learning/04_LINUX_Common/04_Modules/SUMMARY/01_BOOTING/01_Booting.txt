1. === [BOOTING PROCESS on SOC] ===
== Before power up
 - Bootloader (SPL, main) + SW (dtb, OS, rfs) -> mass memory flash (out of SoC)
== At power (boot ROM -> bootloader (eMMC or SD))
 - PC p= reset vector's addr => boot ROM decides PC=eMMC or SD card
 - CPU EXE from PC => load SPL -> SR
 - SPL init DR/clk/wdg, <- main
== Boot trap
 - [SPL -> Bl] = CPU exe 1st ins of bootloader
 - [Bl] CPU - the rest DR
 - [Bl] CPU - load dtb + OS (kernel, initrfs)
== End of Boot trap
 - [Bl -> krn] = CPU exe 1st ins of OS
 - [krn] - CPU - **load initramfs** (take I/O drivers, tools (modprobe)) -> mount ro SD card
 - [krn] - CPU -> init process (PID1): read /etc/initab
   + (re)mounts SD card (rfs) rw:
   + services/daemons
   + usable state (login, graphics)


2. === [BOOTING PROCESS SOC vs MCU] ===
 - Single core >< Multi core
 - internal flash >< external (eMMC, SD card)
 - Flash -> application >< Boot ROM -> SPL -> main -> kernel
