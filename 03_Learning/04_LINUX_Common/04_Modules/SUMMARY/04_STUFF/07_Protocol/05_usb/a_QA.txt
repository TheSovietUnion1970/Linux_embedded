=== USB Physical Layer ===
1. What are D+ and D- lines?
 + D+ -> green
 + D- -> white
 
2. What is pull-up resistor used for in USB?
 + Device connection >< always presence
   * Full -> D+
   * Low  -> D-

3. Difference between full-speed and high-speed signaling?
 + Speed
 + Backward compatibility from high to full
 + Apply: audio, mice >< drive, video

 + USB remote wakeup	- dev - signal - sleep host

8. Speed negotiation
 - Idle: Both - LOW when no device
 - connection - > D+/D- change (know the speed + device here)
 - reset -> D+/D- LOW by host ~ 10ms
 - speed -> by dev (confirm) - J state as default
    + D- HIGH -> LS
    + D+ HIGH -> FS
    + chirp signaling -> HS
       - chirp K		: device -> host
       - chirp K,J,K,J,...	: host   -> device

9. NAK vs STALL
  - NAK: 	V request >< X process or No -> data
  - STALL:	N request -> unrecoverable error
