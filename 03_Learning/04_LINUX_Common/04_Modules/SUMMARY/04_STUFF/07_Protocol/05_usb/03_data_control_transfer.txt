============= USB Transaction:
	SETUP phase			        <PID>
	  SOF			: Idle + Sync + SOF     + | Frame no.   | + | CRC5  | + EOP + Idle	
	  Token packet		:               SETUP   + | ADDR + ENDP |   |       |
	  Data packet		:               DATA0/1 + |DATA[bMPktSz]| + | CRC16 |
	  Handshake packet	: 		ACK     + |      X      |   |   X   |
	  
	DATA phase (IN or OUT)
	  SOF:
	  Token packet		: 		IN/OUT
	  Data packet:
	  Handshake packet	:		ACK/NAK/STALL
	  
	STATUS phase
	  SOF:
	  Token packet		: 		IN/OUT
	  Handshake packet	:		ACK/NAK/STALL
	  
============= PID:
SOF	0xA
SETUP	0xD

DATA0	0x3
DATA1	0xB

OUT	0x1
IN	0x9

ACK	0x2
NAK	0xA
STALL	0xE

PRE	0xC
SPLIT   0xE

============= Field size:
Sync	-> 8 (FS/LS) or 32 (HS)
PID 	-> 8 = 4 bit (H) + 4-bit check field (L)
Frameno	-> 11, MAX - 7FF
ADDR	-> 7
ENDP	-> 4
DATA	-> 0 - 1024 - DEFINED: bMaxPacketSize

============= Standard - Class - Vendor:
Standard-Class
Vendor		- if dev func X covered - standard USB spec

Most common: standard-dev, class-if

============= Ex:
- READ USB Transaction GetDesc_pkt
	const u8 GetDesc_pkt[8] = {
	    0x80,       // bmRequestType: Device-to-host, Standard, Device
	    0x06,       // bRequest: USB_REQ_GET_DESCRIPTOR
	    0x00, 0x01, // wValue: Descriptor Index = 0 (LOW), Type = DEVICE (1) (HIGH)
	    0x00, 0x00, // wIndex: 0
	    0x12, 0x00  // wLength: 18 bytes (Device descriptor length)
	};
	SETUP.SEND -> SETUPphase.Datapacket.DATA[8] = GetDesc_pkt
	DATA.RECV  <- DATAphase.Datapacket.DATA[8]
	     	   <- DATAphase.Datapacket.DATA[8]
	     	   <- DATAphase.Datapacket.DATA[2]

- WRITE USB Transaction SetAddr_pkt	     
	const u8 SetAddr_pkt[8] = {
	    0x00,       // bmRequestType: Host-to-device, Standard, Device
	    0x05,       // bRequest: USB_REQ_SET_ADDRESS
	    0x01, 0x00, // wValue: Device address: 1
	    0x00, 0x00, // wIndex: 0
	    0x00, 0x00  // wLength: 0
	};
	SETUP.SEND -> SETUPphase.Datapacket.DATA[8] = SetAddr_pkt
	DATA.SEND  -> NO data packet as wLength = 0
