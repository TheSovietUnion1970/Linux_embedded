D+H, D-L -> 1
D+L, D-H -> 0

J state - default
   D+H, D-L -> 1 : full speed
   D+L, D-H -> 0 : low speed
K state
   D+L, D-H -> 0 : full speed
   D+H, D-L -> 1 : low speed

SE0
   D+L, D-L
SE1
   D+H, D-H

==================================================
For full speed:
  State J = 1
  State K = 0
vice versa ...
