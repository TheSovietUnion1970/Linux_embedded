DVFS = Dynamic Voltage + Frequency Scaling

	cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_available_governors
	conservative ondemand userspace powersave performance : -> CHANGE FREQ

		powersave	     -> low perform

		conservative(better) -> balance - freq - up/down effiecntly
		ondemand	     -> balance - -> high when more load

		userspace	     -> set freq manually

		performance	     -> best form
		
		
		
	Governor	- DECIDE freq based on CPU load
	CPUFreq Driver	- Change freq
	Regulator	- Change VOL based on OPP table
	OPP Table	- Operating Perf Points = MAP voltage - freq
		Ex: 1GHz   - MIN voltage of 1.3V
		    300MHz - MIN voltage of 1.0V
