RX rate: 
	wl1271_rx_handle_data:
		wl1271_rx_status:
			status->signal = ((desc->rssi & RSSI_LEVEL_BITMASK) | BIT(7));
				-> rssi = radio signal strength -> show value in dBm, negative values
					/ -55 dBm -> very good
					/ -85 dBm -> poor
				
				
			status->freq = ieee80211_channel_to_frequency(desc->channel,
						status->band);
				/ status->freq is usually 0x994 = 2452 -> 2.4 GHz
				/ every channel is associated with predefined freq -> Internally looks up a table and returns
					Ex: Ch 2 - 2417 MHz, Ch 5 - 2432 MHz
				/ if status->freq = 0 -> mac80211 thinks the received frames (Beacon, Authentication, Association Response, etc.) are invalid
				
			desc->rate -> rate (MB/s) -> shown on tx bitrate (iw wlan0 link)
				/ In BBGW: 
					/ 6.5  MBit/s (long  GI) - MCS0
					/ 72.2 MBit/s (short GI) - MCS7
					/ 1-2  MBit/s	               - poor -> managemnt frames (Beacon, Probe Request/Response, Authentication, Association)
					   = WL18XX_CONF_HW_RXTX_RATE_1/ WL18XX_CONF_HW_RXTX_RATE_2
			   
TX rate:
	wifi_tx_complete_packet:
		wifi_get_last_tx_rate:
			fw_rate = wifi_status_reg->tx_last_rate -> -> shown on rx bitrate (iw wlan0 link)
				 / fw_rate -> its name shows the true speed, its integer val -> idx for mac80211 to use
				 / Ex: CONF_HW_RATE_INDEX_6MBPS -> speed: 6Mbps, its idx = 4 -> rate->idx = 4 (rate->idx is used by mac80211)
			 
			 
STA role:
	wl12xx_cmd_role_start_sta:
		cmd->sta.local_rates = supported_rates
			supported_rates = CONF_TX_ENABLED_RATES | CONF_TX_MCS_RATES | wifi_vif->rate_set;
				/ CONF_TX_ENABLED_RATES -> beacon, association
				/ CONF_TX_MCS_RATES -> transfer
		cmd->sta.basic_rate_set = basic_rate_set
			
Rates (HW bits):
	basic_rate = basic_rate_set = CONF_HW_BIT_RATE_1MBPS | CONF_HW_BIT_RATE_2MBPS => sta_rate_policies / arp_rsp / probe_req (bitrate_masks - 1Mbps)
	rate_set   = wl1271_tx_enabled_rates_get -> enabled_rate | MCS => cap of this STA
		/ -> wifi_acx_set_peer_cap -> setting capibilities, after association
