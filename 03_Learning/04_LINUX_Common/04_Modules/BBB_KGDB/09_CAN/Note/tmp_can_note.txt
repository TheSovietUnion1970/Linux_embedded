================= mask
CAN_IFxMCTL_UMask -> mask used (Msk[28:0], MXtd, and MDir)
CAN_IFxCMD_Mask => transfer msk to/from IFx and msg obj
================= mask dir
If some bits of the mask bits are set to “don’t care,” the corresponding bits of the arbitration
register will be overwritten by the bits of the stored data frame.
Ex: 
if1arb |= (1u << 29); // W
if1msk &=~ (1u << 30); // mask = no acceptance filtering
	=> still works for reading data frame as the bit 29 of data frame will overwrite bit 29 of arb register
	
if1arb |= (1u << 29); // W
if1msk |= (1u << 30); // mask = acceptance filtering
	=> don't works for reading data frame as the bit 29 of data frame will not overwrite bit 29 of arb register (arb bit 29 still remains 1)
	
================= mask ID
if1arb |= 0x100 << 18;
if1msk |= (0x700 << 18); 
	=> 0h1xx will be accepted >< 0h0xx will not be accepted as bit 8 must be 1 for matching
